# Knowledge Area

Owner: learner approves changes. This directory is the course's *Engineering Knowledge* boundary (`KNOWLEDGE_STANDARD_ADDENDUM.md`). It is empty until concept documents are needed.

- A concept document is the canonical home of one language-independent concept. Each concept has exactly one document; everything else links to it.
- Structure: `KNOWLEDGE_STANDARD.md` §3. Completeness test: §12.
- Folders are by domain (for example `databases/`, `concurrency/`, `distributed-systems/`) and are created when the first document needs one.
- `languages/typescript/`, `languages/go/`, `languages/rust/` hold only what is specific to that language, linking to the concept document instead of repeating it.
- Create a document when the learner asks for one, or when an authored unlock lists one as needed. Do not write concept documents in advance.
