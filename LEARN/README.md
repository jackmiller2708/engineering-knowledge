# LEARN: self-paced learning material

One folder per unlock, named by its ID (for example `P0-GO-01/`). Each folder is a complete, ordered course for that unlock, prepared before the learner is asked to begin.

## How a folder is organised

| Item | What it is |
|---|---|
| `README.md` | **Start here.** Where to begin, time guide, completion requirements, honest status of the material |
| `01-….md`, `02-….md`, … | The sections, studied in order. Each has a goal, steps to do, and questions to attempt |
| `hints/` | Staged hints for the main exercise, small to large |
| `answers/` | Answer keys and explanations. Kept apart on purpose: attempt first, then open |
| `recall/` | Short cards for spaced review, answered from memory after a delay |
| `examples/` | Runnable code that the material refers to |

## Conventions

- Study the sections in order, at your own pace. Nothing needs to be reported in chat to move on.
- Questions live inside the sections. Try them before opening `answers/`.
- Commands are given for **Linux (Zsh), the primary environment**, and **Windows (PowerShell 7)**, which is secondary. Where they differ, both are shown and labelled. Anything not run on that platform by the author says so.
- Output shown as "observed" was produced by the author in a Linux container. It is never a claim about your machine.
- `examples/` holds teaching code only. Your own work (PRJ-LABS, PRJ-ENGINE) stays in your own workspace, not in this repository.
- Asking for help is always allowed: paste the error and say which section you are in.
